## 🇬🇧 English

**FIT IS LIFE** is a premium, high-performance front-end web application designed for a modern fitness studio. Built with a focus on raw aesthetics, dynamic user experience, and immersive micro-animations, this project serves as a showcase for advanced UI/UX development without relying on heavy frontend frameworks.

### Features
- **Cinematic Parallax Backgrounds**: Thematic, high-quality visuals integrated seamlessly behind each section with smooth parallax scrolling.
- **Dynamic Workout Timer**: A custom-built SVG-based circular timer that dynamically tracks workout and rest intervals with color-shifting UI states.
- **Intersection Observer Animations**: Elements glide into the viewport with custom-calculated delays and smooth transitions for a highly polished feel.
- **Responsive & Accessible Layout**: Carefully structured using modern CSS Grid and Flexbox to ensure pixel-perfect rendering across all devices.
- **Zero-Dependency Architecture**: Built entirely with pure Vanilla JavaScript and CSS3 to maximize performance and maintain total control over the DOM.

### Technologies
- HTML5 (Semantic Structure)
- CSS3 (Custom Variables, Keyframes, Flexbox/Grid)
- Vanilla JavaScript (ES6+, DOM Manipulation, Observers)

### Installation
No complex build steps are required. 
1. Clone the repository.
2. Open `index.html` in your preferred modern browser or serve via a local development server (e.g., Live Server).

## 🇹🇷 Türkçe

**FIT IS LIFE**, modern ve elit bir fitness stüdyosu için tasarlanmış, yüksek performanslı premium bir web arayüzü (front-end) projesidir. Çarpıcı bir tasarım dili, dinamik kullanıcı deneyimi ve akıcı mikro-animasyonlar odağında geliştirilen bu proje; ağır kütüphanelere veya framework'lere dayanmadan ileri seviye UI/UX yeteneklerini sergilemek amacıyla oluşturulmuştur.

### Öne Çıkan Özellikler
- **Sinematik Parallax Arka Planlar**: Her bölüme özel üretilmiş, sayfa kaydırma hızıyla uyumlu (parallax) çalışan şeffaf geçişli yüksek kaliteli görseller.
- **Dinamik Canlı Antrenman Sayacı**: Çalışma ve dinlenme sürelerini asenkron olarak takip eden, duruma göre arayüz renklerini (yeşil/turuncu) değiştiren özel SVG tabanlı gelişmiş sayaç sistemi.
- **Intersection Observer Animasyonları**: Sayfa kaydırıldıkça ekrana giren elementlerin, özel gecikme (delay) süreleriyle akıcı bir şekilde belirdiği modern scroll geçişleri.
- **Tam Duyarlı (Responsive) Tasarım**: Modern CSS Grid ve Flexbox kullanılarak her türlü masaüstü ve mobil cihazda kusursuz görünecek şekilde optimize edilmiş mimari.
- **Sıfır Bağımlılık (Zero-Dependency)**: Maksimum performans ve kaynak kodu üzerinde tam hakimiyet sağlamak adına dışarıdan hiçbir kütüphane kullanılmadan, tamamen saf (Vanilla) JavaScript ve CSS3 ile inşa edilmiştir.

### Kullanılan Teknolojiler
- HTML5 (Semantik Yapı)
- CSS3 (Özel Değişkenler, Animasyonlar, Flexbox/Grid)
- Vanilla JavaScript (ES6+, DOM Manipülasyonu, Observers)

### Kurulum
Herhangi bir derleme (build) sürecine ihtiyaç duymaz.
1. Projeyi bilgisayarınıza klonlayın.
2. `index.html` dosyasını modern bir tarayıcıda açın veya yerel bir sunucu (örn. VS Code Live Server) üzerinden çalıştırın.
